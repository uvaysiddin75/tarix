# Nazorat ishi — Tarix testlari

Веб-приложение для подготовки к контрольным работам по истории: учебные материалы, тесты, прогресс и AI-помощник.

## Что нужно установить

1. **Node.js** (версия 18 или новее) — скачать с [nodejs.org](https://nodejs.org) (кнопка LTS)
2. После установки откройте терминал (PowerShell или CMD) и проверьте:

```powershell
node -v
npm -v
```

Если команды работают — всё готово.

## Быстрый старт

### 1. Распакуйте проект

Скопируйте папку проекта на свой компьютер, например:

```
C:\Users\ВашеИмя\Documents\история
```

### 2. Установите зависимости

Откройте терминал **в папке проекта** и выполните:

```powershell
npm install
```

> Папку `node_modules` отправлять не нужно — она создаётся автоматически этой командой.

### 3. Настройте `.env`

Скопируйте файл `.env.example` и переименуйте копию в `.env`:

```powershell
copy .env.example .env
```

Откройте `.env` в блокноте и заполните значения:

| Переменная | Описание |
|------------|----------|
| `PORT` | Порт сервера (по умолчанию `3000`) |
| `JWT_SECRET` | Секретный ключ для входа (минимум 32 символа) |
| `ADMIN_EMAIL` | Email администратора |
| `ADMIN_PASSWORD` | Пароль администратора |
| `ADMIN_NAME` | Имя администратора |
| `REGISTRATION_ENABLED` | `true` — регистрация открыта, `false` — только админ |
| `OPENAI_API_KEY` | Ключ OpenAI (для AI-помощника, необязательно) |
| `GROQ_API_KEY` | Ключ Groq (альтернатива OpenAI) |
| `GEMINI_API_KEY` | Ключ Google Gemini (альтернатива) |

> Файл `.env` содержит пароли и ключи — **не публикуйте его** в интернете. Передавайте другу лично.

### 4. Запустите сервер

**Локально (только на вашем ПК):** дважды нажмите `ZAPUSK.bat`

**В интернет + GitHub (отправить ссылку друзьям):** дважды нажмите `ZAPUSK-INTERNET.bat`

```powershell
npm start
```

В терминале появится:

```
Server: http://localhost:3000
```

### 5. Откройте в браузере

Перейдите по адресу: **http://localhost:3000**

Войдите с email и паролем из `.env` (поля `ADMIN_EMAIL` и `ADMIN_PASSWORD`).

## Возможности

- **Тесты** — викторины по темам истории с разными уровнями сложности
- **Обучение** — текстовые материалы перед тестом
- **Прогресс** — сохранение результатов для каждого пользователя
- **AI-помощник** — объяснение ответов и чат по истории (нужен API-ключ)
- **Админ-панель** — просмотр прогресса всех пользователей, импорт вопросов через AI

## Как передать проект другу

### Что включить в архив

- Все файлы и папки **кроме** `node_modules`
- Файл `.env` — лучше отправить **отдельно** (Telegram, WhatsApp)

### Что друг делает у себя

1. Распаковывает архив
2. Кладёт `.env` в папку проекта
3. Выполняет `npm install`
4. Выполняет `npm start`
5. Открывает http://localhost:3000

## AI-помощник

AI работает, если указан хотя бы один ключ в `.env`:

- `OPENAI_API_KEY` — OpenAI (GPT)
- `GROQ_API_KEY` — Groq (бесплатный tier)
- `GEMINI_API_KEY` — Google Gemini

Без ключей приложение работает, но AI-функции будут недоступны.

## Частые проблемы

**«npm не является командой»**  
→ Установите Node.js с [nodejs.org](https://nodejs.org) и перезапустите терминал.

**Порт 3000 занят**  
→ В `.env` измените `PORT=3001` и откройте http://localhost:3001

**Не могу войти**  
→ Проверьте `ADMIN_EMAIL` и `ADMIN_PASSWORD` в `.env`. При первом запуске создаётся учётная запись администратора.

**Ошибка при `npm install`**  
→ Убедитесь, что интернет включён. Попробуйте удалить папку `node_modules` (если есть) и снова выполнить `npm install`.
